# ADR-0006：使用 Qt Widgets 实现 UI

- 状态：已接受
- 日期：2026-08-03

## 背景

早期技术基线曾选择 Qt Quick/QML，但项目维护者不熟悉 QML，并希望能在开发过程中精确理解和掌控每一段界面代码。引入第二种 UI 描述语言会增加学习、调试和长期维护成本。

## 决策

IntentClip 的 UI 使用 Qt 6 Widgets，以 C++ 类组织窗口、面板和控件。不引入 QML，不依赖 `qtdeclarative`。界面仍需保持视图与业务逻辑分层：Widget 负责展示和用户事件，应用服务负责剪贴板、意图编排与推理。

Qt 继续采用动态链接策略，发布时逐项复核实际使用模块的许可与部署文件。

## 后果

项目维护者可以使用统一的 C++ 工具链阅读和调试 UI，减少语言边界。自定义动画和高度动态布局需要更多 Widgets 代码，因此三段式面板应通过小型复合控件和显式状态机实现，避免把所有逻辑塞进一个窗口类。
