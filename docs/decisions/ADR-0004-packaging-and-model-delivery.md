# ADR-0004：MSIX 与模型交付分离

- 状态：已接受，模型渠道在发布候选阶段复核
- 日期：2026-08-03

## 背景

把数百 MB 到数 GB 的模型塞进应用包会显著增加安装、更新和审核成本；完全在线下载又会带来首次使用流失、CDN 成本和审核环境可用性问题。

## 决策

应用本体使用 MSIX 从 Microsoft Store 分发。主模型作为经许可审计和 SHA-256 校验的数据，在首次启动中经用户选择后下载，模型版本独立于应用版本。模型不得包含或承载可执行代码。

发布候选阶段必须用真实审核路径验证下载可靠性。若失败率、成本或审核风险超过预算，允许通过新 ADR 切换为商店可选包或随包内置一个可用的微型模型。

## 后果

应用更新更小、模型可独立迭代，但需要可靠的 HTTPS 托管、续传、磁盘预检、哈希与原子安装。商店描述和审核备注必须明确首次模型准备是核心依赖，不能宣传“安装后立即完全离线”而隐瞒下载步骤。
