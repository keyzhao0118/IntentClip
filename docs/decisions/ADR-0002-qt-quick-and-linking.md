# ADR-0002：Qt Quick 前端与动态链接 Qt

- 状态：已废弃，由 ADR-0006 取代
- 日期：2026-08-03

## 背景

产品需要托盘、快捷键、浮层、设置页、DPI 与可访问性支持。Qt Widgets 工程风险较低，但现代浮层和响应式表现需要较多定制；Qt Quick 更适合轻量动效和状态驱动界面。

## 决策

采用 Qt 6 Qt Quick/QML 构建界面，C++20 实现业务、平台与推理边界。Qt 动态链接，发布时只使用已经逐项确认可在所选开源许可下分发的模块，附带许可和归属材料；不修改 Qt 本体作为默认策略。

如果所需模块不适用于 LGPL 开源分发，选择购买商业许可或替换该模块，不能在临近发布时才处理。

## 后果

团队需要建立 QML/C++ 边界规范和 QML 部署检查。动态库会增加打包文件数量，但可降低闭源应用在开源许可履约上的风险。本文不是法律意见，发布主体需对最终模块清单做专业复核。

## 变更

2026-08-03：开发者明确选择 Qt Widgets，以便直接使用熟悉的 C++ UI 技术维护项目。Qt Quick/QML 不再进入工程。
