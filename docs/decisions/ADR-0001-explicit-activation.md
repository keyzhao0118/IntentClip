# ADR-0001：显式触发而非后台监听

- 状态：已接受
- 日期：2026-08-03

## 背景

持续监听剪贴板能减少一步操作，但会让密码、令牌、私人消息等无关内容被应用读取，也会增加资源消耗和用户对“后台监控”的担忧。

## 决策

默认仅在用户执行 `Ctrl+C+C` 双复制手势或备选全局快捷键后读取当前剪贴板文本。观察 Ctrl/C 时序不等于读取内容：应用不记录其他按键、不保存剪贴板历史、不轮询剪贴板，也不在手势触发前自动推理。未来若提供剪贴板监听模式，必须作为单独的高可见度 opt-in 功能，明确范围、暂停状态和保留规则。

## 后果

双复制把“复制”和“触发”合并成一个连贯手势，但需要低级键盘钩子与复制时序测试，并可能被部分安全环境限制。普通组合键作为降级路径。隐私边界仍然清晰：只有完整手势发生后才读取文本。
