# ADR-0003：独立推理工作进程

- 状态：已接受
- 日期：2026-08-03

## 背景

本地模型加载和推理可能发生内存不足、底层后端异常、长时间阻塞或第三方库崩溃。若直接放在 UI 进程，任何问题都会让整个产品退出，并且难以可靠回收模型资源。

## 决策

将 llama.cpp 和模型上下文放入 `IntentClipInference.exe`。主程序通过仅限当前用户的本地 IPC 发送受限请求。协议支持版本协商、消息大小上限、流式 token、取消和健康检查。工作进程崩溃时主程序展示可恢复错误并按限速策略重启。

工作进程不是 Windows Service，不开网络端口，不需要管理员权限。

## 后果

增加 IPC、部署和调试复杂度，但换取 UI 稳定性、资源回收和清晰安全边界。必须增加协议契约测试，确保新旧版本不会错误通信。
