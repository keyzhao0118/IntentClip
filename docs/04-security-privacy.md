# 隐私与安全基线

## 1. 隐私声明摘要

默认配置下，IntentClip 在本机处理用户主动提供的文本，不上传原文、生成结果或剪贴板历史。网络仅用于用户发起的模型下载、更新检查、商店权益验证，以及用户明确提交的反馈。正式发布前仍必须提供可公开访问、持续更新的完整隐私政策 URL。

Microsoft Store 对 Win32 产品要求隐私政策；若访问、收集或传输个人信息，政策需说明数据类型、用途、存储、安全、披露对象和用户控制。生成式 AI 产品还需在商店元数据和 Partner Center 披露，并提供不当内容反馈方式。

## 2. 数据分类

| 数据 | 默认处理 | 持久化 | 网络 |
|---|---|---|---|
| 用户输入文本 | 内存中本地推理 | 否 | 否 |
| 生成结果 | 内存中展示 | 否 | 否 |
| 可选历史 | 用户显式开启后本地保存 | DPAPI 保护 | 否 |
| 设置 | 本地配置 | 是 | 否 |
| 模型文件 | 本地模型目录 | 是 | 仅下载 |
| 诊断事件 | 不含原文的本地日志 | 有限保留 | 默认否 |
| 用户反馈 | 发送前预览字段 | 用户决定 | 明确同意后 |
| 商店权益 | 最小必要标识 | 缓存 | Store API |

## 3. 默认规则

- 不持续监听剪贴板；只在快捷键触发后读取。
- 日志禁止写入原文、结果、剪贴板内容、提示词拼接结果、访问令牌或完整路径中的用户名。
- 历史、遥测、崩溃上传均为关闭；启用和撤回在同一设置区域完成。
- 反馈表单默认只附应用版本、模型 ID、错误类别和匿名诊断；文本附件需单独勾选。
- 删除历史必须删除索引、内容和临时文件；模型删除单独确认。
- 不申请与功能无关的 Windows capability，不绕过系统权限或安全机制。

## 4. 威胁模型

| 威胁 | 风险 | 控制 |
|---|---|---|
| 敏感文本进入日志 | 隐私泄漏 | 编译期日志字段白名单、测试扫描、生产禁用 payload 日志 |
| 恶意/损坏模型 | 崩溃、资源耗尽 | 可信清单、HTTPS、SHA-256、大小上限、格式预检 |
| 模型输出被当作指令 | 任意操作 | 输出视为不可信文本；动作由枚举映射，不解析 shell/URL 命令 |
| IPC 被其他进程注入 | 文本泄漏或伪造 | 当前用户 ACL、随机会话令牌、协议版本、消息大小上限 |
| 超长输入导致拒绝服务 | 内存/卡顿 | 字符/token 上限、预估、取消、工作进程隔离 |
| 下载被替换 | 供应链攻击 | 版本化 URL、哈希校验、清单签名方案预留 |
| DLL 搜索劫持 | 代码执行 | 安全 DLL 搜索路径、绝对路径加载、打包清单校验 |
| 反馈误传原文 | 非预期外传 | 默认不附带、发送前字段预览、可撤回同意说明 |

## 5. AI 安全边界

- 分类输出必须通过 schema 验证；未知值映射到 `unknown`。
- 模型不能直接调用剪贴板写入、文件系统、网络、进程启动或商店购买。
- 对疑似医疗、法律、财务高风险文本显示用途限制，不把结果表述为专业建议。
- 应用需提供“不当结果”入口；报告进入人工可处理的支持渠道，并有删除与响应流程。
- 模型卡公开说明训练方、许可、已知限制、基准硬件和产品内的实际用途。

## 6. 保留与清除

- 普通日志按大小滚动且最多保留 7 天；崩溃转储默认仅保存在本机。
- 可选历史保留周期由用户选择，默认建议 30 天；支持立即全部清除。
- 模型下载临时文件在失败、取消或下次启动清理。
- 卸载后由 MSIX 管理的应用数据应被移除；用户主动导出的文件不自动删除。

## 7. 发布前安全检查

- 威胁模型复审、依赖漏洞扫描、SBOM 和第三方许可清单完成。
- 检查安装包中不存在调试符号泄漏、密钥、测试模型、内部 URL 和个人路径。
- 对模型文件、下载清单和所有 PE 文件记录哈希。
- 验证非管理员账户、标准 Windows Defender 配置和断网环境。
- 隐私政策与实际数据流逐项对照；任何新增联网行为必须先更新文档与 UI 同意流程。
