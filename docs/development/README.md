# 开发记录

本目录用于精确记录 IntentClip 的实现过程。每个里程碑单独成文，包含目标、文件变化、关键代码、构建命令、调试问题、验证结果和后续事项。

## 记录规则

- 只记录实际完成和验证过的内容，不把计划写成完成项。
- 每次引入依赖时记录来源、版本、vcpkg triplet 和链接目标。
- 每次调试记录“现象—原因—修改—验证”，避免只留下最终代码。
- 架构或产品行为变化同时更新对应 PRD、体验规格或 ADR。
- 构建产物不提交仓库；可复现配置必须提交。
