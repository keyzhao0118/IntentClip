# 体验设计规格

## 设计原则

- **少打断**：一次触发、一次选择、一个结果。
- **可预期**：显示将使用的文本范围和将执行的动作。
- **可撤销**：首版只复制结果，不直接改写第三方应用内容。
- **渐进披露**：普通用户看到“轻量/均衡/高质量”，高级设置才出现线程数、上下文等术语。
- **不伪装确定性**：低置信度时使用“你可能想要”，不使用“已识别为”。

## 核心流程

### 首次启动

1. 欢迎页：一句话价值、完全本地的边界、生成内容可能有误。
2. 设备检测：系统版本、架构、可用内存、磁盘、CPU 能力；不给设备贴“差”的标签。
3. 模型选择：推荐一个默认档位，展示下载/安装体积和典型内存。
4. 隐私页：默认关闭历史与遥测；链接到完整隐私政策。
5. 快捷键：尝试注册默认组合，冲突时立即处理。
6. 练习：提供非敏感示例文本，完成首次成功。

### 日常拾意

1. 用户在任意应用中按住 `Ctrl` 并连续按两次 `C`，或快速执行两次 `Ctrl+C`。
2. 第一次复制仍由当前应用正常处理；第二次复制确认唤起 IntentClip，产品不吞掉原应用的按键。
3. 面板立即显示，Content 区域填入最新剪贴板文本；Intent 区域同时展开并显示本地识别 loading。
4. 识别完成后，Intent 区域显示按匹配度降序排列的 3–5 个预设功能。
5. 用户勾选一个功能后立即开始执行，Result 区域展开并显示生成 loading，随后流式渲染结果。
6. 用户复制结果、停止、重试、改选另一功能，或关闭面板返回原应用。

## 主面板规格

面板采用单列三段式结构，宽度保持稳定，高度随区域展开，避免内容到达时整个面板横向跳动。

### Content

- 面板出现时立即可见，标题为 `Content`，显示文本来源、字符数和敏感内容提示。
- 正文允许编辑。用户编辑后，当前 Intent 和 Result 立即失效；停止旧任务并在 350 ms 防抖后重新识别。
- 默认展示合理高度，长文本内部滚动；不得只把截断预览送给模型而不告知用户。
- 提供清空和重新读取剪贴板操作。

### Intent

- 触发后立即展开，不等 Content 动画结束；loading 文案为“正在本机理解这段文本…”。
- 结果为 3–5 个纵向或自适应网格功能项，显示图标、功能名和一句短说明。
- 控件视觉上 checkable，但行为是 radio-style 单选；当前激活项有勾选态和运行态。
- 不向用户显示伪精确百分比。排序即表达推荐程度，低置信度时增加“不太确定”提示。
- 用户选择新功能时，旧功能取消勾选；若旧结果正在生成，立即取消并将 Result 切换到新任务。

### Result

- 用户选择功能后才展开；先显示功能名、loading 和停止按钮，再流式追加结果。
- 完成后提供主操作“复制结果”，次操作包括重试、反馈；复制成功给出短暂非阻塞确认。
- 结果文本可选择、可滚动，代码与普通文本采用不同渲染但均视为不可信内容。
- 错误状态保留 Content 和 Intent，让用户可以重试或改选功能，而不是关闭整个面板。

## 信息架构

- **主面板**：Content、Intent、Result 三段式渐进展开工作区。
- **模型页**：当前模型、健康状态、磁盘与内存、切换/修复/删除。
- **设置页**：常规、快捷键、行为、隐私、性能、高级。
- **关于页**：版本、更新通道、模型卡、第三方许可、隐私、支持。

## 状态文案基线

| 状态 | 推荐表达 |
|---|---|
| 正在分类 | “正在本机理解这段文本…” |
| 正在生成 | “正在本机生成，可随时停止” |
| 已复制 | “结果已复制” |
| 模型未就绪 | “需要先准备本地模型，文本不会上传” |
| 内存不足 | “当前可用内存不足以加载此模型，可切换轻量模型” |
| 低置信度 | “不太确定你的意图，你可以直接选择一个操作” |
| 内容风险 | “结果可能不准确，请勿直接用于高风险决策” |

## 安全交互

- 任何反馈上报前，单独列出将发送的字段；原文和生成结果默认不勾选。
- 下载模型前显示来源、许可证摘要、大小、哈希校验和删除方式。
- 打开外部链接前显示真实域名；模型输出中的链接默认作为文本处理。
- 清除数据要列出范围；清除模型与清除历史分开，避免误删大文件。
- 不用“100% 私密”“绝不出错”等绝对宣传语。

## 可访问性与本地化

- 所有控件具备可访问名称、键盘焦点与清晰焦点环。
- 200% 缩放下不遮挡关键按钮；支持高对比度和减少动画偏好。
- 颜色不作为唯一状态信号；错误同时提供图标和文字。
- 简体中文为首发主语言，英文为同时支持语言；UI 文案不得硬编码在 QML。
- 快捷键、日期、数字和文本方向为后续本地化保留结构。
- Intent 功能项必须可用方向键移动、Space/Enter 选择；loading 时焦点不能丢失。

## 原型验证任务

在正式实现前用可点击原型验证 5 个任务：首次准备模型、拾取并总结、低置信度改选动作、停止生成、清除数据。每个任务至少 5 名目标用户，记录完成率、用时、误解和信任顾虑；任何任务成功率低于 80% 都要修订流程。
