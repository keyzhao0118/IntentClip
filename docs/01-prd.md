# 产品需求文档（MVP）

## 1. 范围

MVP 必须形成一条完整闭环：首次启动 → 准备模型 → 用户主动拾取文本 → 识别意图 → 选择动作 → 本地生成 → 复制结果 → 可查看或清除本地状态。

## 2. 功能优先级

### P0：缺失即不能发布

| 能力 | 要求 | 验收标准 |
|---|---|---|
| 首次启动 | 说明本地 AI、磁盘/内存需求、模型许可与隐私 | 用户可取消；未准备模型时主界面给出明确下一步 |
| 全局触发 | 默认 `Ctrl+C+C` 双复制手势；提供普通组合键备选 | 不吞掉复制按键；常见应用中触发可靠；可暂停或改键 |
| 文本输入 | 支持剪贴板文本和手动粘贴 | 空、超长、二进制或不支持格式有清晰提示 |
| 三段式面板 | Content、Intent、Result 按任务进度渐进展开 | 各区域 loading、success、empty、error、cancelled 状态完整 |
| 意图识别 | 返回 3–5 个候选、置信状态和推荐原因 | 只能引用预设功能 ID；按匹配度降序；不合法输出被拒绝或重试一次 |
| 核心动作 | 总结、改写、翻译、解释、提取、回复 | 每类有稳定提示模板和回归样例 |
| 结果区域 | 勾选功能后立即执行，流式显示、停止、重试、复制 | 同时只有一个 active 功能和一个生成任务；停止后 1 秒内结束展示 |
| 模型管理 | 校验、加载、卸载、删除、失败恢复 | 哈希错误不加载；磁盘不足可恢复 |
| 隐私控制 | 默认不保存原文；一键清除缓存和历史 | 清除后无可恢复的应用明文记录 |
| 资源保护 | 内存预检、并发限制、取消和超时 | 低资源时不强行加载；单实例只运行一个生成任务 |
| 反馈入口 | 可报告不当 AI 输出，不默认附带原文 | 用户明确选择是否附上文本和诊断信息 |
| 关于与许可 | 展示版本、开源许可、模型来源、隐私政策 | 离线可访问核心许可文本和模型卡摘要 |

### P1：公测后进入

- 自定义意图与提示模板。
- 经用户明确开启的本地历史，并使用 Windows DPAPI 保护。
- 多模型切换、低内存模式与硬件加速后端。
- 结果对比、收藏模板、导出配置。
- Microsoft Store Pro 权益和跨设备权益恢复。

### P2：明确延后

- OCR、语音、浏览器扩展、团队同步。
- 云模型回退、账号体系和跨设备文本历史。
- 自动替换其他应用中的选中文本。
- 可执行第三方插件和自治代理。

## 3. 意图分类协议

分类器只能输出受约束 JSON：

```json
{
  "language": "zh-CN",
  "content_type": "message",
  "candidates": [
    {
      "intent": "reply",
      "score": 0.91,
      "confidence": "high",
      "reason_key": "looks_like_received_message"
    }
  ],
  "safety": "normal"
}
```

首发功能来自[意图功能矩阵](08-intent-matrix.md)。分类结果必须返回 3–5 个不重复的已注册功能，按 `score` 降序；当有效功能不足 3 个时由规则层补齐通用功能。`score` 只用于本次候选排序，不在 UI 中显示成“准确率”，也不宣称为经过校准的概率。不得让模型自由生成可执行命令、URL 或系统调用。

## 4. 面板状态机

```text
Hidden
  └─ Ctrl+C+C → ContentReady + IntentLoading
       ├─ 分类成功 → IntentReady
       │    └─ Check(function) → ResultLoading
       │         ├─ 生成完成 → ResultReady
       │         ├─ 用户停止 → ResultCancelled
       │         └─ 生成失败 → ResultError
       ├─ 分类失败 → IntentFallback
       └─ Content 变化 → 取消旧请求并重新分类
```

- Content 区域在面板出现时立即可见；Intent 区域同时展开 loading。
- Intent 候选用 checkable 控件呈现，但 MVP 是**单一激活选择**：选择新功能会取消旧生成并替换 Result 内容，不并行运行多个功能。
- 功能一旦被用户选中就立即执行，不再增加二次“运行”按钮。
- Result 区域在选择功能后展开 loading，并尽快流式渲染首批 token。
- 面板关闭会取消仍在进行的分类或生成，并清理本次内存文本。

## 5. 边界与异常

- 空文本：不调用模型，显示“先复制或粘贴一段文本”。
- 超长文本：显示长度与预计资源；默认截断只用于预览，不静默截断生成输入。
- 密码/令牌疑似内容：本地提示敏感信息风险，不上传，不记录。
- 模型未安装或损坏：进入模型修复流程，不回退到网络模型。
- 低置信度：展示通用动作列表并允许用户自行选择。
- 推理崩溃：主程序保持运行，释放工作进程并提供重启。
- 多次触发：新的完整 `Ctrl+C+C` 手势视为明确的新任务，取消旧分类/生成，用最新剪贴板文本重置三段区域。
- 手势误触：托盘菜单可暂停 `Ctrl+C+C`；设置中可调整双击窗口或改用普通组合键。
- 剪贴板暂时被占用：在有限时间内重试读取；超时后保留面板并提示手动粘贴。
- 分类无有效候选：展示由规则层提供的通用功能，不让 Intent 区域永久 loading。

## 6. 关键用户故事

- 作为隐私敏感用户，我能在使用前确认文本不会被上传。
- 作为第一次使用的用户，我无需理解“模型、量化、上下文窗口”也能选到合适配置。
- 作为低配设备用户，我会在下载模型前看到资源需求，而不是下载后才发现无法使用。
- 作为高频用户，我能在不离开当前应用的情况下获得建议并复制结果。
- 作为商店审核员，我无需账号或特殊硬件即可验证核心功能，所有依赖都被明确说明。

## 7. 发布验收

- P0 全部通过自动或人工验收。
- 模型基准集、低资源测试、断网测试、安装/升级/卸载测试有报告。
- 商店描述、截图与真实功能一致；明确披露本地生成式 AI。
- 隐私政策 URL、支持 URL、反馈通道可用。
- 所有二进制、字体、图标、模型和数据集完成许可清单审计。
